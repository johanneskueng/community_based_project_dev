# Getting Started Guide

## Welcome to the Sociocultural Project Development Environment

This guide will help you get started with using the environment for your participatory projects.

## 📥 Installation

### Option 1: Web Browser (Recommended)

1. Open your web browser (Chrome, Firefox, Edge, or Safari)
2. Navigate to the application URL (provided by your administrator)
3. The application will load and can be used immediately
4. For offline use, your browser may prompt you to "Install" or "Add to Home Screen"

### Option 2: Desktop Application

1. Download the installer for your operating system:
   - **Windows**: Download the `.exe` file and run it
   - **macOS**: Download the `.dmg` file and drag to Applications
   - **Linux**: Download the `.AppImage` or `.deb`/`.rpm` package

2. Follow the installation prompts
3. Launch the application from your desktop or applications menu

### Option 3: Mobile Application

1. **Android**: Download from Google Play Store
2. **iOS**: Download from Apple App Store
3. Open the app and follow the setup prompts

## 🚀 First Steps

### 1. Create Your First Project

1. Click on "New Project" or "Create Project"
2. Enter a **Project Title** (e.g., "Community Water Access Improvement")
3. Add a **Description** explaining the project's purpose
4. Set the **Start Date** and **Estimated Duration**
5. Define the **Geographic Scope** (Local, Regional, National)
6. Select the **Primary Language** for the project
7. Choose your **Data Protection Level** (High, Medium, Low)
8. Click "Create Project"

### 2. Invite Team Members (Optional)

If you're working with a team:

1. Go to "Team" or "Users" section
2. Click "Invite User" or "Add Team Member"
3. Enter the person's name and email (if applicable)
4. Select their **Role**:
   - **Professional**: Full access to all features
   - **Community Member**: Can contribute data and view project information
   - **Stakeholder**: Limited access, can view and comment
   - **Evaluator**: Access to evaluation features
5. Set their **Language Preference**
6. Configure **Accessibility Settings** if needed
7. Click "Invite" or "Add"

### 3. Configure Your Profile

1. Click on your profile icon or name
2. Go to "Settings" or "Profile"
3. Update your **Name** and **Contact Information**
4. Set your **Language Preference**
5. Configure **Accessibility Settings**:
   - Text Size (Small, Medium, Large)
   - Color Scheme (Light, Dark, High Contrast)
   - Screen Reader Support (On/Off)
   - Keyboard Navigation (On/Off)
6. Save your settings

## 📝 Understanding the Workflow

The application follows a **7-phase workflow**:

### Phase 1: Setup ✅
*You just completed this by creating your project!*

### Phase 2: Pre-Project 📱
**Purpose**: Collect initial data from community members and professionals

**What you can do**:
- Create text notes from discussions and chats
- Upload and annotate photos
- Document observations
- Tag data with keywords
- Organize data by source type

**How to**:
1. Navigate to the "Pre-Project" or "Data Collection" section
2. Click "Add Note" to create a text entry
3. Click "Upload Photo" to add visual documentation
4. Use the tag system to categorize your data
5. Add accessibility notes for screen readers

### Phase 3: Topic Selection 🎯
**Purpose**: Organize collected data into topics and select focus area

**What you can do**:
- Review all collected data
- Create clusters of related data
- Name and describe each cluster
- Select the primary topic for your project

**How to**:
1. Go to the "Clustering" or "Topic Selection" section
2. Drag and drop data entries into clusters
3. Create new clusters as needed
4. Name each cluster with a descriptive title
5. Select one cluster as your primary project focus

### Phase 4: Situation Analysis 🔍
**Purpose**: Develop comprehensive understanding through systematic analysis

**What you can do**:
- Use participatory methods (community mapping, focus groups)
- Conduct desk reviews (literature, existing data)
- Perform interviews (key informants, stakeholders)
- Identify needs for intervention

**How to**:
1. Navigate to "Situation Analysis"
2. Choose a method to start with
3. Document your findings
4. Identify and prioritize needs
5. Create a stakeholder map

### Phase 5: Conceptualisation 📊
**Purpose**: Develop the theoretical foundation and practical plan

**What you can do**:
- Create Theory of Change
- Map stakeholders
- Define intervention plan
- Plan resources and budget
- Develop monitoring and evaluation concept

**How to**:
1. Go to "Conceptualisation"
2. Start with the Theory of Change builder
3. Add stakeholders and their relationships
4. Define your intervention activities
5. Create your budget
6. Set up your M&E framework

### Phase 6: Implementation 🚀
**Purpose**: Execute the intervention plan with ongoing monitoring

**What you can do**:
- Track activity progress
- Collect monitoring data
- Adjust implementation based on findings
- Generate reports

**How to**:
1. Navigate to "Implementation"
2. View your activity timeline
3. Update activity status and progress
4. Record monitoring data
5. Generate progress reports

### Phase 7: Evaluation 📈
**Purpose**: Assess outcomes and impact

**What you can do**:
- Conduct final evaluation
- Analyze all collected data
- Document lessons learned
- Create final report

**How to**:
1. Go to "Evaluation"
2. Answer evaluation questions
3. Document findings
4. Create your final report
5. Share with stakeholders

## 💡 Tips for Success

### Data Collection Tips
- **Be specific**: Include details like date, time, location, and participants
- **Use tags**: Tag data with relevant keywords for easier organization
- **Add context**: Explain the situation or conversation that led to the data
- **Respect privacy**: Be mindful of personal information and sensitive data

### Clustering Tips
- **Start broad**: Create a few large clusters first, then refine
- **Look for patterns**: Group data that addresses similar themes or issues
- **Involve the team**: Get input from community members on cluster names
- **Be flexible**: It's okay to move data between clusters as you learn more

### Analysis Tips
- **Triangulate**: Use multiple methods to confirm findings
- **Involve stakeholders**: Get input from community members throughout
- **Document everything**: Keep detailed notes on your analysis process
- **Be critical**: Question your assumptions and look for alternative explanations

## ❓ Frequently Asked Questions

### Q: Do I need an internet connection?
**A**: No! The application is designed to work completely offline. You only need internet if you want to sync data between devices or with team members.

### Q: How do I backup my data?
**A**: Go to "Settings" > "Data Management" > "Export Data". You can export all your project data as a file that can be restored later.

### Q: Can I use the application in my language?
**A**: Yes! The application supports multiple languages. You can change your language preference in your profile settings.

### Q: What if I make a mistake?
**A**: Most actions can be undone. Look for "Undo" buttons or check the "Version History" for documents. For critical mistakes, you can restore from a backup.

### Q: How do I share data with my team?
**A**: There are several options:
1. **Export/Import**: Export data and share the file with team members
2. **Local Sync**: If on the same network, use the local sync feature
3. **Cloud Sync (Optional)**: If configured, data can sync automatically

### Q: Is my data safe?
**A**: Yes. All data is stored locally on your device by default. We follow privacy-by-design principles and don't collect any data without your explicit consent.

### Q: Can I use the application on multiple devices?
**A**: Yes! You can install the application on multiple devices and sync data between them using the sync feature.
