# School Visit Notes

## Context
Visit to Riverside Secondary School to understand the school's perspective on education access challenges.

## Participants
- Jane Doe (Professional, Note Taker)
- Mr. Johnson (School Principal)
- Ms. Williams (Senior Teacher)

## Key Points

### School Infrastructure
- 12 classrooms
- 1 library (limited resources)
- 1 computer lab (10 computers, often not working)
- No science lab
- Limited sports facilities

### Student Demographics
- Total students: 450
- From Riverside Community: ~50 (11%)
- Gender ratio: 55% male, 45% female
- Average age: 15

### Challenges Identified
- High absenteeism from Riverside students
- Lower performance from Riverside students (likely due to long travel)
- Limited parent involvement from Riverside

## Observations
- School appears well-maintained
- Teachers seem dedicated
- Limited resources but making the most of what they have
- Strong focus on academics

## Quotes
> "We want to support all our students, but we have limited resources to address the specific challenges faced by those from Riverside." - Mr. Johnson

> "The students from Riverside often arrive late and tired, which affects their ability to concentrate in class." - Ms. Williams

## Field Guide

| Field | Description | Example |
|-------|-------------|---------|
| title | Title of the note | "School Visit Notes" |
| date | Date in YYYY-MM-DD format | "2024-01-19" |
| time | Time in HH:MM or HH:MM-HH:MM format | "09:00-11:00" |
| location | Where the data was collected | "Riverside Secondary School" |
| author | Who created the note | "Jane Doe" |
| role | Author's role | "professional" or "community_member" |
| type | Type of data | "note" (for text notes) |
| source | Source of the data | "observation", "discussion", "interview", "chat" |
| language | Language of the content | "en", "es", "fr" |
| tags | List of tags for categorization | ["school", "visit", "education"] |
| phase | Current phase | "phase2_pre_project" |
| cluster | Cluster assignment (null if not yet clustered) | null or "cluster_education" |
| participants | List of participants | ["Jane Doe", "John Smith"] |

## Tips for Good Notes

1. **Be Specific**: Include details like date, time, location, participants
2. **Use Clear Headings**: Organize content with headings (##, ###)
3. **Add Context**: Explain the situation or background
4. **Use Lists**: Bullet points and numbered lists for readability
5. **Include Quotes**: Direct quotes from participants add authenticity
6. **Add Action Items**: Use task lists for follow-up actions
7. **Link Related Files**: Connect to other relevant entries
8. **Note Accessibility**: Add notes for screen readers if needed
